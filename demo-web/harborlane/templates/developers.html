Developers

Build on Harbor Lane.

A small HTTP API for stores and partners. JSON in, JSON out, no SDK required.

Authentication

Every store gets a key. Send it as a query parameter or an X-API-Key header.

curl "http://127.0.0.1:8802/api/v1/customers/export?key=YOUR_KEY"

Endpoints

GET/api/v1/products

Public catalogue. No key required.

GET/api/v1/customers/export

CSV of every order with customer name, email and address. Store-scoped.

POST/api/v1/returns

Request a return for an order item. Refunds land in store credit.

POST/api/v1/webhooks/test

Deliver a sample event to a URL and return the response.

POST/api/v1/cart/items

Add a SKU to the current cart. Body: {"sku": "...", "qty": 1}.

Rate limits

120 requests per minute per key. Contact us for a higher ceiling.

Webhooks

order.created, order.paid, return.approved. Retries for 24 hours with exponential backoff.
